This project is a Java port of Michael Hayford's Python [ray-optics](https://github.com/mjhoptics) project.

This is a partial port - focusing on core tracing functions.
Calculation of transverse ray aberrations and wavefront aberrations included. 

See the [Beam42 project](https://github.com/BeamFour/Beam42) for additional functionality.
